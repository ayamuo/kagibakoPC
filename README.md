# Kagibako（鍵箱）

Windows で使う、自分専用のパスワード管理アプリです。

- ファイル形式 `.kagi`：**Argon2id + AES-256-GCM**（改ざん検知付き）
- データは外部に送信しません。この PC と、自分で選んだ保存先（クラウドの同期フォルダなど）にだけ置かれます
- **デグレ検出**：古い版での上書き・アップロード漏れを検出し、端末内の控えから正しい版へ戻せる
- **比較・統合**：別々の場所で編集したファイルも、項目単位で統合（共通の元の版がわかれば自動）
- **偽サイト対策**：登録した URL から「公式サイトを開く」、自動入力前のドメイン照合、怪しいドメインの警告、アプリ内の安全ガイド
- **自動入力**：ボタンまたはホットキー（既定 Ctrl+Alt+A）で、ブラウザやアプリに ID・パスワードを打ち込む
- **パスワード履歴**・**自動バックアップ**・**CSV の取り込み／書き出し**（Chrome・Edge・Bitwarden・KeePass など）

## ダウンロード

[Releases](https://github.com/ayamuo/kagibakoPC/releases/latest) から `Kagibako-（版数）-windows-x64.zip` をダウンロードし、好きな場所（例: `C:\Tools\Kagibako`）に展開して `Kagibako.exe` を起動します。インストールは不要です。

- 必要なもの：Windows 10/11（64bit）、Microsoft Edge WebView2 ランタイム（Windows 10/11 には通常入っています）
- 「Code → Download ZIP」で取れるのはソースコードです。使うだけなら Releases の zip を使ってください

## 偽サイト対策（いちばん大事な使い方）

**メールや SMS のリンクからはログインしない。** Kagibako に登録した URL の「🌐 公式サイトを開く」か、ブックマークから開きます。

自動入力は、入力の直前にブラウザ（Chrome / Edge / Brave / Vivaldi / Opera / Firefox）のアドレスバーを読み取り、アイテムに登録した URL の**登録ドメイン**と照合します。

| ページのアドレス | 登録 URL が `https://login.yahoo.co.jp/` のとき |
| --- | --- |
| `https://login.yahoo.co.jp/…` | ✅ 入力する |
| `https://accounts.yahoo.co.jp/…` | ✅ 入力する（同じ yahoo.co.jp） |
| `https://yahoo.co.jp.secure-login.com/…` | ⛔ 止める（実体は secure-login.com） |
| `https://yahoo-co-jp.com/…` | ⛔ 止める |

- アドレスバーの読み取りはブラウザ自身のツールバーだけを見ます（ページの中身は見ないので、偽サイトがページ内に「それっぽいアドレス」を書いても騙されません）
- 一致しないときは入力せず、「公式サイトを開く（推奨）」を案内します。正規の別ドメイン（例: ログインだけ別ドメインのサービス）は、確認のうえアイテムごとに「許可ドメイン」として追加できます
- https で登録したアイテムは、http のページには入力しません
- URL を登録するときに、国際化ドメイン（似た別の文字）・数字だけのアドレス・http・ハイフンの多いドメインを警告します
- 免責事項（初回起動時に同意）と、よくある手口・見分け方・被害に遭ったときの連絡先をまとめた「安全ガイド」をアプリ内で読めます

## 自動入力

- **アイテム画面の「⌨ 自動入力」**：直前に使っていたウィンドウ（「入力先: 〜」に表示）へ入力します。ログイン画面の ID 欄をクリック → Kagibako に切り替えて押す、の流れです
- **ホットキー（既定 Ctrl+Alt+A）**：ログイン画面で押すと Kagibako が前に出て、そのサイトのドメインに合うアイテムが一番上に並びます。Enter で入力（Shift+Enter ならパスワードだけを、いまカーソルのある欄に入力）。どのアイテムともドメインが合わないときは「偽サイトでは？」と警告します
- **スマート入力（既定）**：Tab で移動せず、ページ内の ID 欄・パスワード欄を探してそこへ入力します。欄の間に「ログイン状態を保持」のチェックボックスやリンク、「パスワードを表示」ボタンがあっても崩れません。2段階のログイン画面ではパスワード欄が現れるまで最大3秒待ちます。パスワード欄が見つからないときは、違う欄に打ち込まないよう入力を止めて案内します
- 入力の手順はアイテムごとに選べます（おまかせ、ID→Tab→パスワード→Enter、2段階のログイン画面用など）。記号: `{USERFIELD}`（ID欄へ移動）`{PASSFIELD}`（パスワード欄へ移動）`{ID}` `{PASSWORD}` `{ITEM1}` `{ITEM2}` `{TAB}` `{ENTER}` `{DELAY 1000}` など
- 日本語入力がオンでも崩れないよう、入力の間だけ自動でオフにします
- 入力の途中で別のウィンドウに切り替わったら、その時点で中止します（パスワードを違う場所に打ち込まないため）
- 設定で「× で閉じてもタスクトレイに常駐」にすると、ホットキーをいつでも使えます
- 管理者権限で動いているアプリには、Windows の仕組み上入力できません

## パスワード履歴・点検・バックアップ・CSV

- **パスワード履歴**：パスワードを変えると、変更前の値を最大20件残します（アイテム画面の「履歴」）
- **パスワードの点検**：使い回し・弱いパスワード・暗証番号らしいものを一覧にします
- **自動バックアップ**：保存のたびに、暗号化したままの `.kagi` を `ドキュメント\Kagibako\backup` に残します（世代数・保存先は設定で変更可。OneDrive などの同期フォルダにすると PC の故障にも備えられます）
- **CSV**：メニューから取り込み／書き出し。列は自動で判定し、違っていれば手で直せます。CSV はパスワードが暗号化されないので、使い終わったらすぐ削除してください

## 使い方

展開したフォルダの `Kagibako.exe` をダブルクリックで起動します。ブラウザもサーバーも不要です。exe を右クリック →「スタートにピン留め」や、デスクトップにショートカットを作ると便利です。

- 起動すると、前回開いたファイルのパスワード入力から始まります（設定で変更可。別のファイルは下の「別のファイルを開く」から）
- **使うときだけ起動する**想定です：ブラウザでログイン画面を開く → Kagibako を起動 → ロック解除 → アイテムの「⌨ 自動入力」。起動直前に使っていたウィンドウが入力先になります
- 二重に起動すると、すでに開いている Kagibako が前に出るだけです
- コピーした ID・パスワードは、Windows のクリップボード履歴（Win+V）とクラウドのクリップボード同期に残らない形でコピーし、30 秒後に消します
- Windows のロック（Win+L）・スリープ・サインアウトで Kagibako もロックします。シャットダウン時の未保存の変更は暗号化して一時保存し、次に開いたときに復元を案内します
- 開いたファイルにそのまま上書き保存できます（「最近使ったファイル」にも残ります）
- 端末内の控え・設定は `%LOCALAPPDATA%\Kagibako` に保存されます
- 画面は `app` フォルダを、PC内だけの仮想アドレス `https://kagibako.example/` で表示しています（ネットワークには出ません。URL を開く操作は既定のブラウザに渡します）

本物のサイトを使わずに試すには、テスト用ログインページを起動します（この PC の中だけで動き、入力内容はどこにも送られません。Node.js が必要です）。

```bash
node tools/test-login-server.mjs
```

### ファイルの受け渡し（同期はしない運用）

`.kagi` ファイルは、クラウドの同期フォルダや USB メモリなどに置いて、複数の PC で使えます。各 `.kagi` には「第何版か・いつ・どの端末で保存したか・それまでの版の系譜」が記録されます（改ざんすると復号できなくなる形で保護）。

### デグレ検出と復旧

各 PC は、最後に扱った版とその前の版（最大30版）を**暗号化したまま**端末内に控えとして残します。ファイルを開くと、その控えと比べて次のように判定します。

| 判定 | 意味 | アプリの動作 |
| --- | --- | --- |
| 同じ版 | 前回と同じ | そのまま開く |
| 新しい版 | 別の PC で更新された | そのまま開き、控えを更新 |
| **古い版（デグレ）** | アップロード漏れ・古いファイルで上書きされた | 警告。「この端末の新しい版を使う（推奨）」「比較して統合」「古いまま開く」から選択 |
| 分岐 | 別々の場所で編集した | 「比較して統合」で項目ごとに統合 |

さらに保存するときは、**保存先のファイルが開いた後に更新されていないか**と、**この PC で扱ったより新しい版の変更が入っているか**を確認し、問題があれば保存の前に止めて統合を提案します。

### 比較・統合

メニュー「別のファイルと比較・統合」で、任意の2つのファイルを比較できます。

- 共通の元の版がわかる場合（同じファイルの系譜どうし）は**3方向比較**：片方だけが変えた項目は自動で反映し、両方が変えた項目だけ確認
- わからない場合は、更新日時が新しい方を初期値にして項目ごとに選択
- 削除も記録しているので、片方で削除したアイテムが復活しない。フォルダの名前変更・削除も反映

## セキュリティ

- 鍵の導出：Argon2id（64MiB / 3回 / ソルト128bit）
- 暗号化：AES-256-GCM（保存のたびに新しい IV。ヘッダの版情報も含めて改ざん検知）
- 自動ロック（既定5分）。未保存の変更はロック時に暗号化して一時保存し、次に開いたときに復元
- 画面を離れたら即ロック（設定）
- コピーしたパスワードは30秒後にクリップボードから消去（設定で変更可）
- パスワード生成（`crypto.getRandomValues`、偏りなし）と強度表示
- 厳しい Content-Security-Policy（外部通信なし・インラインスクリプトなし）、他サイトへの埋め込み禁止
- 外部ライブラリは Argon2 実装の [hash-wasm](https://github.com/Daninet/hash-wasm) 4.12.0（MIT）のみを同梱（同梱物とライセンスの一覧は [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)）
- ドメインの境界の判定に、公式の [Public Suffix List](https://publicsuffix.org/)（Mozilla Public License 2.0）を `app/js/psl-data.js` として同梱（更新: `tools/psl` に取り直して `node tools/build-psl.mjs`）

**マスターパスワードを忘れると誰にも復元できません。**

## 補足：`.idm` ファイルの読み込み

`.idm` 形式のファイルも「ファイルを開く」で開けます（読み込みのみ）。開いた後に「保存」すると、`.kagi` 形式の新しいファイルとして保存されます。`.idm` 形式は暗号が古く（Blowfish・鍵の強化なし・改ざん検知なし）総当たりに弱いため、`.kagi` で保存し直したら元の `.idm` ファイルは削除してください。

- `.idm` ファイルのパスワードは Shift_JIS で 56 バイトまでです
